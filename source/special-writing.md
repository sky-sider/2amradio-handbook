# 特別放送 企画・お便り制作ガイド — 「いつもと違う夜」を書くために

> **開発資料 v1.3／ゲーム本体 v4.9.22**。シナリオライター・プランナー向け。**引用した番組名と仕組みは実装を確認**し、**本文中の作例・新企画は創作例（ゲームには未実装）**として分けてあります。

## このガイドの使い方

「特別放送を何にするか」を考える人は、[現行21企画のカタログ](#theme-catalog) → [新企画の素案](#pitch-bank) → [企画シート](#pitch-sheet)へ。参加するリスナーの原稿を書く人は、[放送の流れ](#program-flow) → [シチュエーション図鑑](#patterns) → [一通の原稿シート](#letter-sheet)へ進んでください。

**特別放送の基本思想**：何か大事件を起こす夜ではなく、同じ街の12人が、一つの募集にそれぞれ違う答えを見つける夜。投稿していない人にも、一日があります。

### 実現状況の区別

| マーク | 意味 |
|---|---|
| **現行** | v4.9.22に同種の企画・演出・条件がある。ただし発生は確約されない。 |
| **追加原稿** | 既存のテーマや記憶をもとに文章を足す案。配達条件の追加実装が必要な場合がある。 |
| **追加演出** | 現行の操作範囲で構成案を実現できるが、**自動でその順序や組み合わせになる保証はない**。強制には改修が必要。 |
| **新企画** | 新しい特別放送を登録する案。募集・冒頭・締め・参加原稿・選択肢への追加が必要。 |
| **拡張設計** | 後日の強制連作や全員参加、特殊演出など、**既存の仕組みだけでは足りない**案。 |

## 特別放送が生まれて、余韻を残すまで

<h2 id="program-flow">放送の流れ — ひと晩では完結しない</h2>

1. **企画が候補に上がる**：定番・空想・季節・物語由来など。第29夜以降の開催可能な夜に選べる。第3章（51〜64夜）の期間には通常の新規募集ができない。
2. **今夜、募集を告知**：番組で企画を選ぶ。通常の放送の最後に、テーマ・募集文を発表する。
3. **告知を聴く／書く／書きかける**：全員が聴くわけではない。聴いた人も投稿・下書き・聴くだけに分かれる。投稿の起こりやすさには人物の傾向・希望・親しさ・投稿休止が影響する。
4. **翌夜、本番**：専用投稿を最大5通優先しつつ、通常のお便りも混ざる。放送で紹介できるのは**最大3通**。送った人全員の手紙が読まれるわけではない。
5. **本番を実際に聴いた人の記憶**：本番の聴取は告知の聴取と別に決まる。自分の投稿が紹介されて喜ぶ人、聴くだけで帰る人もいる。
6. **翌夜の感想**：条件が合えば、本番を聴いた非応募者の「昨日の特別放送」が候補に加わる。別の便箋が優先され、**必ず配達・紹介されるとは限らない**。

### ライターが必ず区別する五つの線

- **告知を聞いた** ≠ **応募した**。
- **応募した** ≠ **本番で紹介された**。
- **告知を聞いた** ≠ **本番も聞いた**。
- **手紙が局に届いた** ≠ **町じゅうに内容が知られた**。
- **企画のきっかけになった手紙がある** ≠ **その人物の私生活を局がすべて知っている**。

> **設定上の注意**：特別放送では投稿者の選択や聴取判定が実際に変わります。一方、シナリオライターが原稿を追加しただけでは、特定の人を確実に登場させたり、全員を参加させたりすることはできません。

### 既存企画を増やす前に考えること

新しい題名が既存の21企画と本当に違うか見てください。「心に残った言葉」と「持って帰った一言」は似ていますが、後者なら**今日実際に耳にした一言／その一日での行動**に限定するなど、書く人が違いを実感できる約束を作れます。

## 変化する要素を、企画の言葉に直す

| 変化するもの | ライター向けの問い | 企画にできる展開 |
|---|---|---|
| 気持ち・希望 | 今夜は人に話したい夜か、聴くだけの夜か | 同じ募集に応募する／見送る |
| 番組との親しさ | この番組に、どのくらい言葉を預けられるか | 同じ出来事でも短い報告／少し深い話になる（深い文面は追加原稿） |
| 仕事・疲れ・休息 | 書く時間と気力があるか | 告知に気づいても応募しない／翌日だけ書く |
| 実際の生活行動 | 今夜の話題に合うことを本当にしたか | 自慢大会の昨日の小さな行為／季節の追伸 |
| 公開済みの手紙 | 番組にどんな話が**実際に**届き、紹介されたか | 同じ街・昔の好きなことなどの物語企画が生まれる |
| 誰が本番を聴いたか | 放送が誰の生活へ残ったか | 翌日感想、孤独感やうれしさの小さな変化 |
| 章と節目の位置 | 今夜は企画を開ける夜か | 50・100・200・300・365・500夜の記念特番 |

<h3 id="p01">P01　毎日ある「小さな自慢」を拾う</h3>

**区分：現行**　／　**起こるきっかけ**：第29夜以降、開催可能な通常夜に定番企画を選ぶ

> **原稿・演出の作例**：パン屋「今日は自分で焼いたパンを自分で買いました」

**書くときの注意**：褒めるに値する成果より、本人が気に入った小さな行為を探す

<h3 id="p02">P02　いつもの道具から空想が始まる</h3>

**区分：現行**　／　**起こるきっかけ**：選べる3種類の不思議な企画から選択

> **原稿・演出の作例**：古時計「もし時計が話すなら、時間の管理以外は担当外と言うでしょう」

**書くときの注意**：道具が本当に話した事実にしない

<h3 id="p03">P03　一通の放送がみんなの企画へ育つ</h3>

**区分：現行**　／　**起こるきっかけ**：実際に紹介された便箋と本人の日常の記録が一致し、物語企画の提案が生まれる

> **原稿・演出の作例**：猫の「絵の余白」の手紙 → 皆の「昔好きだったもの」

**書くときの注意**：個人の秘密を勝手に公開する企画へ拡大しない

<h3 id="p04">P04　複数の声から「言いそびれ」を見つける</h3>

**区分：現行**　／　**起こるきっかけ**：金魚・配達員・終点などの公開済み話題と生活条件が重なる

> **原稿・演出の作例**：みんな違う相手に、うまく言えない言葉がある

**書くときの注意**：未紹介の相談は企画発案の公的根拠にしない

<h3 id="p05">P05　実際の街の暮らしが企画の種になる</h3>

**区分：現行**　／　**起こるきっかけ**：配達員と古時計の街での接点、または公開済みの街の手紙と生活が基礎

> **原稿・演出の作例**：街にいる知らない人にも、それぞれの帰り道がある

**書くときの注意**：局が二人の接触の全貌を知っていると思わせない

<h3 id="p06">P06　新しいテーマを提案する</h3>

**区分：新企画**　／　**起こるきっかけ**：タイトル・募集文・冒頭・締め・12人の原稿などを新設し、候補へ追加する

> **原稿・演出の作例**：「帰り道の落とし物」募集：失くした物でも、見つけた時間でも

**書くときの注意**：新しい題名を書くだけで、ゲームに自動で表示されるわけではない

<h3 id="p10">P10　気持ちに余裕があっても投稿は確率的</h3>

<h3 id="p11">P11　しばらく投稿を休んでいるので応募しない</h3>

**書くときの注意**：企画に参加しない＝番組から離れたと断定しない

<h3 id="p12">P12　まだ初登場していない人は応募しない</h3>

> **原稿・演出の作例**：新しい常連の初登場前に、その人名義の記念投稿は来ない

**書くときの注意**：12人を初夜から全員出演させない

<h3 id="p13">P13　応募がゼロでも放送は続く</h3>

## 新しい特別放送を考えるための企画アイデア集

<h2 id="pitch-bank">新企画10案 — 企画名・募集文・2人の声まで</h2>

以下は**すべて新規アイデアであり、v4.9.22には未登録**です。新企画は、単にテーマのタイトルを決めるだけでなく、リスナー12人の答えの違い、番組のオープニングと締め、実施条件、他企画との違いまでセットで検討してください。

### 提案 01｜落とし物の行方

**募集文案**：なくした物、拾った物、見つからなかったものを教えてください。

**この企画の核**：物から、人との距離と日常を描く

> **作例①**：終点のひとつ前「落としたのは切符ではなく、確かめる時間かもしれません」
>
> **作例②**：眠れないパン屋「計量スプーンが見つからず、いつも使う手を探しました」

**実装・監修メモ**：通常の新テーマ登録で制作可／実際の落とし物との連動は追加条件。

### 提案 02｜小さな失敗の展覧会

**募集文案**：人には見せていない、ちょっとした失敗を一つ展示してください。

**この企画の核**：笑えるが傷つかない、自嘲はほどほどに

> **作例①**：午前3時の配達員「主任の前で格好よく駐車したかったんですが」
>
> **作例②**：三角定規「完璧な円を描こうとして、定規を使いました」

**実装・監修メモ**：新テーマ／「失敗＝成長した」と固定しない。

### 提案 03｜今夜だけの閉店時間

**募集文案**：一日を閉じるときの合図を募集します。店でも、家でも、心の中でも。

**この企画の核**：昼夜の違う仕事と休息

> **作例①**：冷蔵庫の明かり「厨房の火を消す前に、自分の夕飯のことを考えました」
>
> **作例②**：夜明けの猫「パソコンを閉じて、机の紙はそのままにしました」

**実装・監修メモ**：新テーマ／勤務時間と投稿時刻の矛盾に注意。

### 提案 04｜知らない人の親切

**募集文案**：顔も名前も覚えていない人との、ほんの短い出来事を募集します。

**この企画の核**：街の人々の輪郭が浮かぶ

> **作例①**：逆さまの傘「傘を持たない人に屋根を少し貸しました」
>
> **作例②**：透明な金魚「落とした手袋を、誰かが拾ってくれました」

**実装・監修メモ**：新テーマ／実際の二人の交流に結び付けるなら追加条件。

### 提案 05｜もしも一日を採点するなら

**募集文案**：今日を100点にしなくていい、勝手な採点基準を募集します。

**この企画の核**：よくできた／できなかった以外のものさし

> **作例①**：月の裏側「月が出勤していれば本日は合格とします」
>
> **作例②**：古時計「お茶をおいしく飲めたので、もう十分でしょう」

**実装・監修メモ**：新テーマ／勝ち負けや評価で人物を序列化しない。

### 提案 06｜持って帰った一言

**募集文案**：今日どこかで聞いた、家に連れて帰りたくなった一言を募集します。

**この企画の核**：公共の言葉と私的な解釈

> **作例①**：砂糖を三杯「『またどうぞ』が、ずっと耳に残っています」
>
> **作例②**：眠れないパン屋「『次はもう少し』には、まだ続きがあります」

**実装・監修メモ**：既存「心に残っている言葉」と近い。採用前に差別化する。

### 提案 07｜今日は何も決めませんでした

**募集文案**：決めなかったこと、保留したこと、その間にしたことを募集します。

**この企画の核**：行動しないことの主体性

> **作例①**：透明な金魚「返事を書いて、今日は送信しませんでした」
>
> **作例②**：名前はまだありません「今日は、続きを考えただけです」

**実装・監修メモ**：新テーマ／選択しない＝弱さと断定しない。

### 提案 08｜未来の自分への小包

**募集文案**：明日の自分に置いておきたい、小さなものや言葉を募集します。

**この企画の核**：近い未来へつなぐ穏やかさ

> **作例①**：三角定規「明日のノートに、疑問符をひとつ残しました」
>
> **作例②**：古時計「朝の自分のために、湯のみを出しておきました」

**実装・監修メモ**：新テーマ／後日小包を開く話は続編条件の追加が必要。

### 提案 09｜変な習慣の説明会

**募集文案**：自分だけが普通だと思っている、小さな習慣を発表してください。

**この企画の核**：生活から自然に生じるユーモア

> **作例①**：午前3時の配達員「休憩中、猫主任にだけ業務報告をしています」
>
> **作例②**：砂糖を三杯「コーヒーを淹れる前に、カップの置き場を決めます」

**実装・監修メモ**：新テーマ／実際の習慣として定着させる場合は設定監修。

### 提案 10｜同じ町の違う窓

**募集文案**：あなたが好きな、町の窓・灯り・店先・階段の風景を募集します。

**この企画の核**：同じ街の別視点を浮かび上がらせる

> **作例①**：終点のひとつ前「駅の窓は、最終列車の後も明るいです」
>
> **作例②**：逆さまの傘「花屋の窓は、閉店後に少し暗く見えます」

**実装・監修メモ**：新テーマ／同じ場所での同時接触を描くなら追加条件。

## サンプル：一つの新企画を三人で読み比べる

**仮企画『今夜だけの閉店時間』**（未実装）。募集は「一日を終えるときの小さな合図」。同じ問いでも、仕事と生活が違えば答えが変わります。

- **冷蔵庫の明かり「最後の鍋」**：「厨房の火を消したら今日の仕事は終わりです。でも自分の夕飯を用意するのは、そのあとで。最近は、その順番を入れ替えたい日があります。」
- **午前3時の配達員「配送終了の報告」**：「帰ってエンジンを切ったあと、いつも一度だけ『本日の業務終了』と心で言います。猫主任は承認印を押してくれません。私もそれは知っています。」
- **名前はまだありません「画面の暗さ」**：「電気を消したあと、まだ目が慣れない時間があります。今日はそれが、私の閉店時間です。」

**企画の放送順案**：配達員のユーモア → 料理人の日常 → 名前はまだありませんの余白。ただし**現行の自動DJがこの順番を保証するわけではありません**。企画全体の演出にするなら選出ルールの確認が必要です。

## 発生条件を決めるときのチェックリスト

- [ ] 企画の提案理由は実際に**放送済み**の手紙から説明できるか（物語連動の場合）。
- [ ] その人物の最近の行動は、実際に起きたことか。
- [ ] 告知を聴いたか／投稿したか／本番を聴いたか／紹介されたかを区別したか。
- [ ] 投稿しなかった人物も、自然に暮らしを続けられるか。
- [ ] 企画の応募が0通、1通、5通以上でも放送が成立するか。
- [ ] 通常の手紙が混ざり、最大3通しか読まれなくても主題が壊れないか。
- [ ] 手動・おたより中心・聴くだけの夜で矛盾なく見えるか。
- [ ] 新規3人など、まだ登場していない人物を先に出演させていないか。
- [ ] 51〜64夜、記念夜、最終放送の予約との衝突を考慮したか。
- [ ] 0通・未紹介・未聴取でも、DJが知らない情報を語らないか。
- [ ] 内容がただのテーマ違いではなく、12人の新しい日常を描いているか。
- [ ] 長期プレイでも同じ原稿・同じ結論ばかりにならないか。

## 「このガイドだけでは実装できないこと」

**新しい特別放送を作るためには**、ゲーム側でテーマを登録し、必要なら候補への出し方・専用返答・条件付き本文・翌日以降の反応を実装します。このガイドは**企画と原稿の設計資料**であり、ここへ書くだけでゲームの開催候補が増えるわけではありません。

重要な制約は、**第29夜以降・章や節目との競合・直近開催からの間隔（通常は7夜以上）**、読書モードの企画選出方針、**通常の3通枠**です。企画の強制開催や全員出演は新規設計を要します。
