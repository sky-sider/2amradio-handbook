# 第100夜以降の最終放送と閉局

> **資料基準:** ゲーム v4.9.22 ／ **資料状態:** 実装コードを基準にした開発者向け整理。未検証・提案は明記。

## 位置づけ

第100夜の放送を終えたプレイヤーは、**いつでもではなく、記念放送等と競合しない通常放送後**に、任意の最終放送を計画できます。第100夜で自動終了しません。

## 閉局までの基本例

```text
第130夜を放送完了（計画を選ぶ）
  → 第131夜の放送で翌夜の閉局を予告
  → 第132夜は専用の最終放送
  → 関わりの深い3人から最終便箋＋DJの応答
  → 閉局済み（通常放送へ戻れない）
  → 証明書／最後のお便りPNG／記録の閲覧・再開始
```

**重要**：これは第130夜セーブの例。閉局の夜数は計画したタイミングによって変わります。`finaleCanPlan()` の夜数・予約衝突判定を満たす必要があります。

## 状態とフロー

| `finale.status` | 意味 |
|---|---|
| `none` | 閉局未計画。通常放送を続けられる。 |
| `planned` | 予告夜・最終夜を予約。予告前に取消可。 |
| `announced` | 閉局を予告した。次の夜は最終放送。 |
| `on_air` | 最終放送の進行中。 |
| `completed` | 閉局済み。既存セーブで通常放送は続行不可。 |

## 最後の3通の選出

`s.played` の**実際に紹介した履歴**をもとに、紹介回数・章以外の主要便箋・直近の登場などで人物をランキングし、上位3名を選ぶ。各人の役割は概ね「感謝」「寂しさ」「いつもの暮らし」。文面は12人それぞれの語り口と実際に紹介した過去の題名に配慮します。

## 記念画像・記録

- 最終放送記録証明書：局名、閉局した夜、総紹介通数、出会ったリスナー、特別放送、最終3人など。
- 最後のお便り：差出人別の便箋をPNG出力。
- 生成りの紙、落ち着いた文字組み、枠・罫線。**タイトル下の余計な波線、円形の閉局印、消印は付けない**（v4.9.6以降の確定デザイン）。
- 保存後に読み返せるが、通常放送の再開には使わない。

## 安全性

最終放送のステージ変更は `finaleCommit()` による保存成功を条件にし、保存失敗なら元の状態へ戻す。最終放送中の不用意な `reset` はデータ喪失につながるため確認を行う。
